# Agents, por Ciro Cesar Maciel

**A IA trabalhando nas suas ferramentas.** Você pede. O agente faz no computador dele e pede a sua aprovação antes de enviar, pagar, apagar ou publicar.

Esta organização é onde os agentes do [Assistant](https://myagents.click/?ref=github-agents) guardam o trabalho: cada conta ganha um repositório, e cada arquivo que um agente escreve vira um commit em nome dele. Tudo feito por uma pessoa, com uma equipe de agentes.

[**Conhecer o Agents**](https://myagents.click/?ref=github-agents) · [Seguir o Ciro no GitHub](https://github.com/ciro-maciel) · [Cartas do Ciro, toda semana por e-mail](https://ciromaciel.click/?ref=github-agents)

## Os três produtos da linha

| Produto | O que faz | Onde |
|---|---|---|
| **Assistant** | Um agente por trabalho, com conversa, memória e um computador próprio na nuvem (Chrome e terminal). Você vê a tela ao vivo e pode assumir. Mostre uma vez, ele repete. | [myagents.click](https://myagents.click/?ref=github-agents) · por convite |
| **Connectors** | 36 servidores MCP com login no navegador, para o Assistant, o Claude ou qualquer cliente MCP: Search Console, Analytics, YouTube, Agenda, Drive, App Store Connect, CNPJ e CEP, entre outros. | [mcp.myagents.click](https://mcp.myagents.click/?ref=github-agents) |
| **Brain** | A memória dos seus agentes: um espaço por assunto, cada um com o próprio endereço MCP. | [brain.dashboard.myagents.click](https://brain.dashboard.myagents.click/?ref=github-agents) |

Ainda não há planos, e nada é cobrado.

## Baixe de graça: seis apps para Mac, de código aberto

Nativos, MIT, em português e inglês. Se um deles te ajudou, **deixe uma estrela** no repositório. É o que faz outra pessoa encontrá-lo.

| App | O que faz | Instalar |
|---|---|---|
| [Cleaner](https://github.com/ciro-maciel/cleaner) | Limpa o Mac e mostra tudo antes de apagar. Quarentena de 7 dias. | `brew install --cask ciro-maciel/tap/ciro-cleaner` |
| [Screenshots](https://github.com/ciro-maciel/screenshots) | Captura, anotação e gravação de tela. | `brew install --cask ciro-maciel/tap/ciro-screenshots` |
| [Speech to Text](https://github.com/ciro-maciel/speech-to-text) | Aperte uma tecla, fale, e o texto aparece onde está o cursor. Whisper no próprio Mac. | `brew install --cask ciro-maciel/tap/ciro-speech-to-text` |
| [Text to Speech](https://github.com/ciro-maciel/text-to-speech) | Selecione um texto em qualquer app e ouça. | `brew install --cask ciro-maciel/tap/ciro-text-to-speech` |
| [Windows](https://github.com/ciro-maciel/windows) | Janelas no lugar com um atalho ou arrastando até a borda. | `brew install --cask ciro-maciel/tap/ciro-windows` |
| [Assistant de voz](https://github.com/ciro-maciel/voice-assistant) | O Claude Code por voz: diga o nome dele, pergunte, ele responde falando. | `brew install --cask ciro-maciel/tap/ciro-voice-assistant` |

Sem Homebrew? Cada app tem a página de download em [ciromaciel.click/tools](https://ciromaciel.click/tools?ref=github-agents), junto com as outras ferramentas grátis.
